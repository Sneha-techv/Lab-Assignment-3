Student Management System – Java (OOP, Exceptions, Multithreading)

This project implements a complete Student Management System using:

Inheritance

Abstract Classes

Interfaces

Method Overloading & Overriding

Exception Handling (Custom Exception Included)

Multithreading

Wrapper Classes (Integer, Double)

This is developed as part of Java Lab Assignment – Dr. Manish Kumar.

🚀 Features
✅ Object-Oriented Programming

Person → abstract base

Student → extends Person

RecordActions → interface for operations

StudentManager → CRUD operations + validation

✅ Exception Handling

Try–Catch–Finally

Custom exception: StudentNotFoundException

Input validation

✅ Multithreading

Loader class implements Runnable

Simulates loading animation while adding a student

✅ Wrapper Classes

Integer & Double for data conversion

Demonstrates autoboxing/unboxing
